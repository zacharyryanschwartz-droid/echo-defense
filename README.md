# Echo Defense — prototype

Extremely basic playable prototype of a mobile castle-defense concept by **Schwarze Spiele**.

**Play:** https://zacharyryanschwartz-droid.github.io/echo-defense/  (add `?fast=3` to speed it up)

Defend 3 walls over 5 waves: build archer towers, repair walls, cast Fireball / Freeze / Mend.
After each run, **NEXT DAY** turns your recorded habits into an *Echo* that attacks your weakest point the next day.
Single self-contained `index.html` (vanilla JS + canvas). Progress is saved in localStorage; use Reset to clear.
